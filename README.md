EcoRaíz - versión web corregida según feedback docente

Esta versión incluye la carpeta public completa, no solo archivos modificados.
Por eso debe verse correctamente al abrir public/index.html o al ejecutar Live Server.

Archivos principales modificados:
- public/index.html
- public/assets/styles/styles.css

Archivos importantes incluidos para que no aparezca la pantalla en blanco:
- public/assets/scripts/main.js
- public/assets/images/logo.svg
- public/assets/images/hero-plant.svg
- public/app.html
- public/dashboard.html
- public/contacto.html
- public/assets/scripts/app.js
- public/assets/scripts/dashboard.js
- public/assets/styles/dashboard.css

Cómo probar:
1. Descomprime el ZIP.
2. Abre la carpeta EcoRaiz_web_feedback_COMPLETO_v2 en VS Code.
3. Abre public/index.html con Live Server.
4. Si usas la URL, debe ser algo como: http://127.0.0.1:5500/public/index.html
