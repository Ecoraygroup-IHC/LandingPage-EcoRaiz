# EcoRaíz Landing Page

Landing page responsive y mobile-first para EcoRaíz, proyecto de EcoRay Group.

## Archivos incluidos

- `index.html`: página principal de la landing page.
- `contacto.html`: pantalla de contacto con formulario validado con JavaScript.
- `styles.css`: estilos responsive, paleta, componentes y layout.
- `script.js`: menú móvil, animaciones y validaciones del formulario.
- `assets/icons/logo.svg`: logo de EcoRaíz.
- `assets/img/hero-plant.svg`: ilustración principal.

## Cómo ejecutar

Opción 1:
1. Abre la carpeta del proyecto.
2. Haz doble clic en `index.html`.

Opción 2:
1. Abre el proyecto en Visual Studio Code.
2. Instala la extensión Live Server.
3. Haz clic derecho en `index.html` y selecciona `Open with Live Server`.

## Navegación

El enlace `Contacto` del menú y del footer redirige a `contacto.html`. El formulario valida campos obligatorios, formato de correo y muestra un mensaje de éxito.


## Cambio de tema

La landing incluye un botón de cambio de tema. La preferencia se guarda en el navegador mediante localStorage y se mantiene entre `index.html` y `contacto.html`.
