Quick help

Resolve frequent questions without waiting for a response

Before sending a message, review these answers and first steps for using EcoRaíz.

How do I start using EcoRaíz?

Enter “Try EcoRaíz”, register your basic information and select your user type: resident, expert or entrepreneur.

What should I do if a plant appears in critical status?

Review the preventive alert, apply the indicated recommendation and record the corrective action from the dashboard.

Can I test the system without creating a real account?

Yes. The current version includes demo access by segment to view the main features.

Where do I review humidity, light and temperature?

These variables are shown in the dashboard, within the main indicators and the environmental analysis section.
